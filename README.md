# 📚 Estudos e Práticas em Linguagem C

Repositório dedicado ao armazenamento, organização e evolução dos meus códigos desenvolvidos durante a graduação em **Análise e Desenvolvimento de Sistemas** e em cursos complementares de programação.

---

## 📂 Estrutura do Repositório

O repositório está dividido por semestres e módulos temáticos para facilitar a consulta e o estudo prático:

## O que você encontra por aqui

* **Programação em C (1º Semestre):** Exercícios introdutórios, entrada e saída de dados, condicionais, laços de repetição (`for`, `while`, `do-while`), vetores, matrizes, funções e manipulação de strings.
* **Estrutura de Dados (2º Semestre):** Ponteiros, alocação dinâmica de memória (`malloc`, `calloc`, `free`), structs, structs aninhadas e algoritmos de ordenação (Bubble, Selection e Insertion Sort).

## Ferramentas utilizadas
* Linguagem C
* Dev-C++ / GCC
